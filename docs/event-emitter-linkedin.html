CODEFINITY  /  EVENTEMITTER FOR .NET

Decouple your modules
in 3 steps.

Publish a plain event. React to it anywhere.
No interfaces, no base classes, no module references.

1
Publishany object is an event
await events.PublishAsync(new OrderCompleted(orderId));
2
Listenjust an attribute on a method
// Inventory module: runs in the background, after commit
[ApplicationModuleListener]
public async Task Reserve(OrderCompleted e) { … }

// Notifications module: own DI scope, tracked delivery
[ApplicationModuleListener]
public void SendReceipt(OrderCompleted e) { … }
3
Registerone line per module
services.AddEventEmitter()
    .AddListener<InventoryListener>();
